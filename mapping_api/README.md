# Mapping API (copy for deployment)

A copy of the LegalCompass transition API from the research repository (`src/sb_api`, `src/sb/corpus.py`,
`src/sb/mapping.py`) and the published dataset files, so the demo can be deployed from this one repository.
Unchanged except that files are read as UTF-8 (needed on Windows). If the dataset or API changes in the research
repository, copy those files here again. Dataset: IEEE DataPort, DOI 10.21227/h4wg-7413, CC BY 4.0.
